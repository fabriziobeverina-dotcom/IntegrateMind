**PART 3 — PHASE CALCULATION**

**3.1 Logic**

Calculate phase from `ceremony_date_approx` on every app open (server-side, returned in the auth/session response). If `ceremony_date_approx` is null, phase is `none`.
```
days_since_ceremony = today - ceremony_date_approx

if days_since_ceremony <= 7:    phase = 'acute'
if days_since_ceremony 8–30:    phase = 'integration'
if days_since_ceremony 31–90:   phase = 'deepening'
if days_since_ceremony > 90:    phase = 'long_term'
```

**3.2 Phase labels shown in UI**

| Phase | Internal value | Label shown |
|---|---|---|
| Acute | acute | *"The opening"* |
| Integration | integration | *"The settling"* |
| Deepening | deepening | *"The roots"* |
| Long-term | long_term | *"The harvest"* |
| No ceremony / not set | none | *(nothing shown)* |

**PART 4 — HOME SCREEN PHASE DISPLAY**

**4.1 Phase indicator**

On the home screen, below the greeting (e.g. "Good morning, Fabrizio"), add a single line of small text:

Format: *"Day 14 · The settling"*

- Day number = days since `ceremony_date_approx`, starting at 1
- Phase label = current phase label from table above
- Font: Inter 400, small, muted color (not primary text color)
- If phase is `none`, show nothing — no empty space, no placeholder

**4.2 Phase indicator tap behavior**

Tapping the phase indicator opens a bottom sheet explaining the current phase. Content per phase:

**The opening** (acute):
> *"The first days after a ceremony are often the most vivid — and the most fragile. The membrane between ordinary and non-ordinary reality is still thin. Rest. Limit stimulation. Let what came through begin to settle before you try to understand it."*

**The settling** (integration):
> *"The initial opening is closing. This is when many people feel the medicine 'fading' — but this is actually when the real integration begins. What you brought back is starting to meet your daily life. Pay attention to friction. That's where the work is."*

**The roots** (deepening):
> *"A month out. The insights are no longer fresh, but they're starting to ask something of you. Not revelation — application. What in your actual life is this asking you to change, release, or build?"*

**The harvest** (long_term):
> *"Three months or more. You're in the long game now. Not everything that was planted has surfaced yet. Some seeds take a year. The practice now is discernment — what to carry forward, what to release, what to let surprise you."*

Bottom sheet dismisses with a downward swipe or tap outside.

**PART 5 — PHASE TRANSITION INTERSTITIALS**

**5.1 Trigger**

On every app open, after phase is calculated server-side, compare to previous phase stored in session. If phase has changed AND the corresponding transition has not been shown (`phase_transition_shown[key] === false`), queue the transition interstitial to display before the home screen loads.

Mark the transition as shown immediately (set to true in DB) before displaying — do not wait for user dismissal, to prevent repeat display on crash/back navigation.

**5.2 Interstitial design**

Full screen. Dark forest green background. Centered content. No navigation elements.

Top: a small phase icon (SVG, nature-based — suggest a simple sun rising for acute→integration, a tree putting down roots for integration→deepening, fruit on a branch for deepening→long_term).

Below icon, large Crimson Text italic:
The new phase label (e.g. *"The roots"*)

Below that, Inter 400, medium, muted white, centered, generous line height:
The transition message (see below).

Bottom: a single button — *"Continue"* — in primary style.

**5.3 Transition messages**

**Acute → Integration:**
*"The first week has passed.*
*The intensity often softens now — and the real integration begins.*
*This is when it matters most to stay with the practice."*

**Integration → Deepening:**
*"You're a month out.*
*What arrived in the ceremony is starting to ask how it wants to change your actual life.*
*The prompts shift accordingly."*

**Deepening → Long-term:**
*"Three months.*
*What's stayed with you?*
*The harvest phase is about discernment — what to carry forward, what to release."*

**PART 6 — PHASE-AWARE PROMPT FILTERING**

**6.1 Prompt tagging**

Add a `phase_tags` field to the prompts table:
```
phase_tags    text[], default '{any}'
              valid values: acute, integration, deepening, long_term, any
```

Tag each of the 77 existing prompts according to this logic:
- Body category prompts: tag all `any` — somatic work is relevant in all phases
- Emotion category prompts: tag days 1–12 as `acute, integration`, rest as `any`
- Social category prompts: tag all `any` except the first 3 — tag those `integration, deepening, long_term` (relational work too early in acute phase)
- Environment category prompts: tag all `any`
- Spirit category prompts: tag first 6 as `any`, remaining as `integration, deepening, long_term`
- Mental category prompts: tag first 6 as `integration, deepening, long_term` (conceptual processing too early in acute phase), rest as `any`
- Milestone prompts (days 73–77): tag all `deepening, long_term`

**6.2 Filtering logic**

When selecting the daily prompt, filter the prompt pool to only include prompts where `phase_tags` contains the user's current phase OR contains `any`. If the filtered pool is empty for the current day position, fall back to any prompt tagged `any`.

If user's phase is `none` (no ceremony set), show only prompts tagged `any`.

**6.3 Acute phase special handling**

If user is in `acute` phase (days 0–7), prepend a small banner above the daily prompt card:

*"You're in the early days. Be gentle with yourself — reflecting can wait if rest is what's needed."*

Amber background, dismissible with an X. Once dismissed, do not show again for 24 hours.

**PART 7 — MEDICINE DISPLAY**

Show `ceremony_medicine` only in the user's own profile page, in a small section labeled *"Your journey"*:

- Phase indicator (same as home screen)
- Medicine worked with (as simple tags/chips)
- Ceremony date approx (shown as month + year only, not exact date — e.g. "March 2026")
- A small edit link that reopens the onboarding screens so the user can update if they work with medicine again

Never show medicine data in community views, admin dashboard, or anywhere else. Medicine is private by definition.

---

**PART 8 — EDGE CASES**

Handle all of these explicitly:

- **User selects "I haven't had a ceremony yet"**: phase is `none`, no day counter shown, no phase indicator, no transition interstitials. All prompts shown are tagged `any`. Show a gentle note on the practices tab: *"If you haven't worked with plant medicine yet, the practices here are still for you."*

- **User selects "I'd rather not say"**: same as above — treat as `none`. Do not ask again.

- **User works with medicine again mid-journey**: the profile edit link allows them to reset `ceremony_date_approx` to today and restart the phase cycle. When this happens, reset `phase_transition_shown` to all false so they see the transition interstitials again for the new cycle. Do not reset seeds or badges.

- **Ceremony date in the future**: not possible given the selector options, but validate server-side — if `ceremony_date_approx` is somehow in the future, treat as day 0 (acute).

- **Phase calculation on day of ceremony (day 0)**: include in acute. Days count from 0.
